## 🚀 Getting Started

### Prerequisites
- JDK 25 (or latest stable JDK)  
- Any Java IDE (IntelliJ IDEA, Eclipse, NetBeans) or text editor  
- Command-line tools for compilation and execution  

### Compile & Run
To compile:
```bash
javac Lab1.java
java Lab1
```
